MNM Server Backup

A private tool, used only by its owner.

MNM Server Backup copies the photo and video library on its owner's home server to the owner's own Google Drive, once a week, so there is a second copy away from home. It is not a public service: nobody else signs in to it.

It runs on the home server with rclone. It uploads new files, keeps the old version when a file changes, never deletes anything on Drive, and regularly checks that every file arrived intact.
