Privacy policy

MNM Server Backup · last updated 18 November 2026

Who uses it

Only its owner. MNM Server Backup is a personal backup tool, not a service offered to anyone else.

What it accesses

The Google Drive of the account that signs in, which is the owner's own. It lists the backup folder, uploads copies of files from the owner's home server, moves replaced versions to an "old versions" folder, and reads file sizes and checksums to confirm the copies are complete.

What it keeps

The Google sign-in token is stored only on the owner's home server. The files go only to the owner's Drive. Nothing is kept anywhere else.

What it shares

Nothing. No data is sent to anyone other than the owner's own Google Drive. There are no analytics, no ads, and no third parties. Data from Google is used only to make and check the backup.

MNM Server Backup's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.
